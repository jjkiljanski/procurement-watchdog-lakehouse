# Gold Layer

Purpose:

- Build stable, daily analytical marts from Silver.
- Provide benchmark-friendly outputs for lifecycle, buyer, market, and daily signal views.

Input:

- `data/silver/bzp_YYYY-MM-DD.parquet`

Primary build entrypoint:

- `scripts/build_gold.py`

Core transformation module:

- `src/procurement/gold/spark_transforms.py`

Outputs (partitioned by date):

- `data/gold/case_mart/date=YYYY-MM-DD/`
- `data/gold/buyer_mart/date=YYYY-MM-DD/`
- `data/gold/market_mart/date=YYYY-MM-DD/`
- `data/gold/signals_buyer_daily/date=YYYY-MM-DD/`

Execution model:

- deterministic from Silver input snapshot,
- idempotent for reruns (`overwrite` target-date partition),
- schema-safe transforms with nested-field presence checks.

Reporting:

- lightweight daily run stats are generated by `scripts/build_run_stats.py` and written to
  `data/reports/run_stats/run_stats_YYYY-MM-DD.{json,md}`.
